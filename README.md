# Rutuparna Purandare — Portfolio

Static GitHub Pages starter for an engineering portfolio.

## Structure
- `index.html` — one-page landing page
- `styles.css` — global visual system
- `projects/` — individual project pages
- `research/` — deep research / technical investigation pages

## Add/remove a project
1. Create a new page in `projects/`.
2. Add one card in `index.html`.
3. Link to the GitHub repo or case study.

For a more scalable version later, this can be converted to Jekyll collections so each project is data-driven.
