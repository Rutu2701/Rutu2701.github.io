Raspberry Pi Surveillance Rover

Wireless mobile rover using a Raspberry Pi for onboard control and camera streaming. The system combines battery-powered drive, wireless command input and live visual feedback.

Exploring my capabilities.

Control

Raspberry Pi runs the onboard control software and handles commands for the mobile platform.

Video

Camera capture and local streaming provide live visual feedback during rover operation.

Connectivity

Wireless network communication is combined with Bluetooth input for remote operation.

Power

Battery operation removes the requirement for a tethered supply during testing and use.

System role

The project explored the integration boundary between an embedded Linux computer, a mobile drive platform and a live sensing interface. The main engineering work was getting these subsystems to behave as one remotely operated machine.
