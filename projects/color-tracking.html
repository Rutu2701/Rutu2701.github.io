PROJECT 06 · EXPERIMENT · OPENCV · PYTHON

Color Tracking Cursor

A camera-based computer-vision experiment that tracks a colored object in real time and maps its relative movement to cursor motion, connecting visual detection to an interactive software control loop.

SKILLS

PythonOpenCVComputer VisionObject TrackingCoordinate MappingReal-Time Processing
EXPERIMENTOPENCVPYTHON

Detection

Camera input is processed to identify and track a selected colour.

Tracking

The detected position is followed frame by frame to produce relative movement.

Mapping

Image-space movement is translated into cursor-space movement.

Interaction

The experiment connects a physical visual gesture to a software input mechanism.

Questions

Common questions presented in an experimental community-style format.

How is the object detected?

Camera frames are processed with OpenCV to identify the selected colour and its position.

VISION QUESTION

Why use relative movement?

Relative mapping connects changes in image position to cursor movement rather than requiring a fixed absolute screen coordinate.

INTERACTION QUESTION

What is the main limitation?

Tracking quality depends on reliable visual detection, so lighting, colour ambiguity and camera conditions matter.

EXPERIMENTAL LIMITATION

What could be explored next?

Smoother filtering, more robust detection and improved mapping would be natural extensions of the experiment.
