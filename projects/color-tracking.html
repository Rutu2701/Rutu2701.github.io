Color Tracking Cursor

A camera-based computer-vision experiment that tracks a colored object in real time and maps its relative movement to cursor motion, connecting visual detection to an interactive software control loop.

SKILLS

PythonOpenCVComputer VisionObject TrackingCoordinate MappingReal-Time Processing
EXPERIMENTOPENCVPYTHON

Detection

Camera input is processed to identify and track a selected colour.

Tracking

The detected position is followed frame by frame to produce relative movement.

Mapping

Image-space movement is translated into cursor-space movement.

Interaction

The experiment connects a physical visual gesture to a software input mechanism.
