PROJECT 07 · COMPUTER VISION · OPENCV · PYTHON

Color Tracking Cursor

Computer-vision experiment using camera input to detect a selected colour, track its image position and map the resulting motion to a software cursor.

Exploring my capabilities.

SKILLS

PythonOpenCVComputer VisionObject TrackingCoordinate MappingReal-Time Processing
EXPERIMENTOPENCVPYTHON

Detection

Camera frames are processed to isolate the selected colour and determine its image-space position.

Tracking

The detected position is updated frame by frame to obtain the object's relative movement.

Mapping

Movement in camera coordinates is scaled and mapped to cursor coordinates.

Control loop

The experiment links a physical visual input to a software interface through a real-time processing loop.

Pipeline

camera input → colour isolation → position extraction → coordinate mapping → cursor control

Engineering focus

The useful part of the experiment is the complete sensing-to-action loop: extracting a stable physical signal from camera data and translating it into a deterministic software input.
