Auto-Circuit for KiCad

An AI-assisted text-to-schematic and PCB compilation workflow for KiCad, exploring how natural-language circuit descriptions can be transformed into structured electronic-design artifacts.

Compiler pipeline

Natural-language circuit description → structured specification → placement → KiCad artifacts.

Output workflow

The repository targets schematic, PCB, BOM, Gerber, STEP and PDF outputs.

Core challenge

Physically valid routing requires spatial reasoning, topology constraints and geometry-aware decisions.

Implementation

Python modules cover specification, compilation, placement, PCB placement and output generation, with tests around the core workflow.

Engineering direction

The interesting problem is not generating text; it is preserving electrical intent while moving from an abstract specification toward physically meaningful EDA data.

The project therefore keeps the design stages explicit: specification → compilation → placement → KiCad output.
