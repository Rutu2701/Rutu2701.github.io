PROJECT 02 · AI · EDA · KICAD

CircuitForge

An AI-assisted text-to-schematic and PCB compilation workflow for KiCad 7, exploring how natural-language circuit descriptions can be transformed into structured electronic-design artifacts.

SKILLS

PythonKiCadEDA AutomationAI APIsNetlist GenerationPCB DesignCompiler Architecture
AIEDAKICAD

Compiler pipeline

Natural-language circuit description → structured specification → placement → KiCad artifacts.

Output workflow

The pipeline targets schematic, PCB, BOM, Gerber, STEP and PDF outputs.

Core challenge

Physically valid routing requires spatial reasoning, topology constraints and geometry-aware decisions.

Development state

An active experiment focused on automating practical parts of electronic design without hiding the underlying EDA workflow.

Questions

Common questions presented in an experimental community-style format.

Why use AI for EDA?

To test whether natural-language circuit intent can be converted into useful structured design data while keeping engineering stages explicit.

DESIGN QUESTION

What is the hardest part?

PCB routing: geometry, topology and physical constraints are harder to represent than a textual circuit description.

OPEN TECHNICAL QUESTION

Does it replace KiCad?

No. The workflow is built around KiCad artifacts and automation rather than replacing the EDA environment.

BOUNDARY

What would you improve next?

More robust routing and validation would strengthen the end-to-end compilation workflow.
